# tree-sitter-modelfile

A tree-sitter grammar for [Ollama](https://ollama.com/)'s Modelfile used for configuration.

This creates a tree-sitter grammar and parser for a Modelfile, and is best utilised with editor extensions or plugins to provide syntax highlighting for Modelfiles.

# Functionality

tree-sitter-modelfile is functional for providing most syntax highlighting, however this is a new project and requires optimisations, testing, and more to ensure it is
functioning correctly. This includes things like creating initial unit tests, and improving the incremental parsing aspects of the grammar.
